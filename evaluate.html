RoadGuard

Evaluation tool (for the research paper)

Back to app

Measure real accuracy

  1. Collect road photos. Label them with a free tool (LabelImg, Roboflow, CVAT) and export YOLO txt files (one .txt per image), or use a labels.json (format below).
  2. Select the images and the label files together (all in one go) and press Run evaluation.
  3. Copy the Markdown table or download the CSV and put the numbers into Table I of the paper.

No labels yet? Choose only images, press Run, then Download predicted labels (JSON). Correct that file by hand and you have a labelled set quickly.

labels.json format

{
  "road1.jpg": [ { "type": "pothole", "x": 0.31, "y": 0.52, "w": 0.18, "h": 0.12 } ],
  "road2.jpg": [],
  "road3.jpg": [ { "type": "crack", "x": 0.10, "y": 0.60, "w": 0.55, "h": 0.08 } ]
}
// x, y = top-left corner, w, h = size, all as a fraction (0 to 1) of the image.
// type is pothole, crack or other. An empty list means plain road.
